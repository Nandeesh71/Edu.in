# Ex 09 – PHP Image File Upload Handling ## AIM To write a PHP script that handles file uploads, allows only JPEG and PNG files, and saves them to a directory. ## Procedure 1. Create `index.html` with a form using `enctype="multipart/form-data"` and `method="post"`. 2. Create `upload.php` to handle the POST request. 3. Read file info from `$_FILES["image"]`. 4. Validate MIME type against an allowed list. 5. Use `move_uploaded_file()` to save the file to `uploads/`. 6. Display success or error message. ## Output ``` Image uploaded successfully! Saved to: uploads/photo.jpg ``` Or if invalid file type: ``` Only JPEG and PNG images are allowed. ``` Image Upload
