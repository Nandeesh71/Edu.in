# Ex 19 — React Router (Home and About pages)

Requirements: Node.js, npm.

Steps:

1. Create a React app and install `react-router-dom`, then replace `src/` with the provided files:

```
npx create-react-app router-app
cd router-app
npm install react-router-dom
# copy ex19_react_router files into router-app/src/
npm start
```

2. Open `http://localhost:3000` and use the navigation links to visit Home and About pages.
