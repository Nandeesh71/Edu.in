# Ex 02 – Styling Web Pages using CSS Box Model and Background Properties ## AIM To apply the CSS Box Model and background properties to style a web page by controlling layout, spacing, and background appearance. ## Procedure 1. Create `index.html` with a `
` element. 2. Link an external `style.css` file. 3. In CSS, set `body` background color and the `.box` width, padding, border, and margin. 4. Open `index.html` in a browser. ### CSS Box Model (Margin → Border → Padding → Content) | Property | Purpose | |----------|---------| | `margin` | Space outside the border | | `border` | Line around the element | | `padding` | Space inside the border | | `width/height` | Content area size | ## Output A white box with a dark border and inner padding, displayed on a light blue background, demonstrating all four layers of the box model.
