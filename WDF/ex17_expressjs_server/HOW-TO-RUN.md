# Ex 17 — Express.js Server Creation and Routing

Requirements: Node.js, npm.

Steps:

1. Change to the exercise folder:

```
cd ex17_expressjs_server
```

2. Install dependencies and start the server:

```
npm install
npm start
```

3. Open a browser at:

```
http://localhost:3000/
```

The server responds with "Hello, Express!" on the root route.
