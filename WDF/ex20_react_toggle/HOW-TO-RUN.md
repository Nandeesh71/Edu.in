# Ex 20 — React ToggleText Component

Requirements: Node.js, npm.

Steps:

1. Create a React app or reuse an existing one and replace `src/App.js` and `src/index.js` with the provided files:

```
npx create-react-app toggle-text-app
cd toggle-text-app
# copy ex20_react_toggle files into toggle-text-app/src/
npm start
```

2. Open `http://localhost:3000` to try the toggle text button.
