# Ex 15 — MongoDB Collection Creation and Document Insertion

Requirements: MongoDB Community Server (mongod) and `mongosh`.

Steps:

1. Start the MongoDB server:

```
mongod
```

2. Run the MongoDB shell and execute the script (either paste the commands or run the file):

```
mongosh
# then paste the commands from collection_insert.js
```

Or run the script file directly with mongosh:

```
mongosh collection_insert.js
```

This will create/use the `studentDB` database and insert a sample document into the `students` collection.
