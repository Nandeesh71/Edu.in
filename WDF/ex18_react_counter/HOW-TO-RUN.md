# Ex 18 — React Counter Component

Requirements: Node.js, npm.

Steps:

1. Create a React app (or use an existing one) and replace `src/` files with the provided ones:

```
npx create-react-app counter-app
cd counter-app
# copy the files from ex18_react_counter into counter-app/src/
npm start
```

2. The app runs on `http://localhost:3000` and shows a simple counter component.
